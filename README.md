# Beautiflized

> Makes Minecraft look beautiful while keeping performance in mind.

## Features

Beautiflized is a visual and performance-focused Minecraft modpack designed to make the game feel more polished without turning it into a heavy, overcomplicated experience.

### ✨ Enhanced visuals
- More detailed and lively Minecraft visuals
- Improved block and entity appearance
- More expressive entity models and textures
- Smoother player animations
- Animated, waving capes
- Improved visual particles and effects
- Dynamic lighting for a more immersive world
- Better-looking leaves, grass, flowers, lanterns, fire, shields, and other details
- Improved block-entity visuals

### 🌄 Shaders and atmosphere
- Optional shader support for a more beautiful and atmospheric Minecraft experience
- Enhanced voxel-style visuals
- Better lighting and environmental presentation
- A visual setup designed to work alongside performance optimizations

### 🎨 Resource-pack improvements
- Refined item and block visuals
- Improved food textures
- Enhanced enchantment and item outlines
- Cleaner icons and interface visuals
- Additional visual details throughout the game

### ⚡ Performance
- Strong rendering-performance improvements
- Reduced unnecessary visual and computational overhead
- Better memory usage
- Optimizations for world and game processing
- Improved performance while maintaining the enhanced visual experience
- Dynamic FPS behavior to reduce resource usage when Minecraft is not actively being used
- Entity culling to avoid rendering things that cannot be seen

### 🧭 Quality of life
- Improved F3 information
- Easier viewing of enchantment information
- Shulker box contents can be previewed more conveniently
- Zoom functionality
- Reloadable language resources
- Improved food and hunger information
- Additional configuration options
- Cleaner and more convenient interfaces

### 🛠️ Extra polish
- Cape support
- Essential multiplayer/social features
- Improved compatibility between visual enhancements and the underlying Fabric ecosystem
- A collection of small improvements intended to make everyday Minecraft gameplay feel smoother and more polished

## Versions

- **Minecraft:** 26.1
- **Fabric Loader:** 0.19.5
- **Pack version:** 2.0.0

## What Beautiflized is for

Beautiflized is made for players who want Minecraft to look noticeably better while still keeping performance as a priority. It combines visual enhancements, shaders, resource-pack improvements, performance optimization, and quality-of-life features into one cohesive setup.
